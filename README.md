# HatchTool

Tools for AutoCAD / Revit `.pat` hatch patterns: a browser bench to view and edit them, a library of our own patterns, and a Sverchok node that hatches regions in Blender.

**Open the bench: https://zeffii.github.io/HatchTool/**

## Bench

Open `.pat` files or a whole folder (or drag them in), pan and zoom, isolate a line family to see its origin and delta, edit the source live. `index.html` is the whole app.

## Pattern library

35 patterns in `patterns/`: bricks, tiles and paving, stone, foliage, materials. Millimetres, with Revit `;%UNITS=MM` / `;%TYPE=MODEL` lines (AutoCAD ignores them). They are generated by `tools/patgen.py` from shapes drawn in one repeating tile, so edit the generator and run `npm run patterns`.

## Sverchok node

`sverchok/` holds the Hatch Pattern node: put `utils/hatch_module.py` in Sverchok's `utils/` and `nodes/hatch_pattern.py` in a node category, then add it to the menu.

- In: one stream per object, Vertices plus Polygons (holes by even-odd) or Edges (closed boundaries), Scale, Offset X / Y. The plane is inferred.
- Pattern: a Blender text block holding `.pat` data.
- Out: Vertices / Edges, Dots, Stroke Vertices / Edges (chained, ordered strokes for plotting), Plane matrix.

## Stairs node

`sverchok/nodes/stairs.py` with `utils/stairs_module.py`: concrete, precast or timber stairs from a plan sketch. In: Boundaries (`[[side], [side]]`), Riser Vertices / Edges (one riser per chain of edges, the top one is the landing edge), Path (walking line, bottom first), Level Start / End. Out: Vertices / Polygons, Rise, Goings. `python3 tools/stairs_preview.py out.png` renders the test sketches.

## The format in one line

`angle, x, y, delta-x, delta-y [, dashes…]`: line *k* passes through `origin + k·(dx·u + dy·n)`, with the delta in the family's rotated frame; dashes > 0 draw, < 0 are gaps, 0 is a dot.

## Development

`npm test` (bench, library) and `npm run test:py` (node and core, needs numpy). Third-party `.pat` files used for testing are not kept in this repository.
