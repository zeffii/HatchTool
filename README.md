# HatchTool

iteration 1

## Hatch Pattern Bench

A single-page viewer and editor for AutoCAD / Revit `.pat` hatch patterns. Open `index.html` in a browser, no build step.

- Open `.pat` files or whole folders (or drag them onto the page). Multi-pattern files such as `acad.pat` are supported, as are Revit `;%TYPE` / `;%UNITS` directives and the DOS end-of-file marker found in older files.
- Pan, zoom, scale and rotate the hatch. Hover or click a line family to isolate it and see its origin and delta.
- Edit the source live and copy the result.

The page opens on the HatchTool pattern library, see below.

## Pattern library

`patterns/` holds 35 patterns drawn for this project, in millimetres, with Revit `;%UNITS=MM` and `;%TYPE=MODEL` lines so they import as model patterns (AutoCAD reads them as plain `.pat`):

- `bricks.pat`: stretcher, stack, English, Flemish, header and soldier bonds on a 225 x 75 module
- `tiles.pat`: square, diagonal, one-third offset planks, hexagon, hopscotch, octagon and dot, fish scale, herringbone at 45 and 90 degrees, basketweave, chevron
- `stone.pat`: random ashlar, flagstone, rubble, cobbles, setts, gravel
- `foliage.pat`: grass, leaves, ground cover planting, marsh
- `materials.pat`: concrete, earth, sand, insulation, timber grain, steel, water, glass

They are generated by `tools/patgen.py`: each pattern is drawn as shapes in one repeating tile and every edge is compiled into an exact line family. Edit the generator, then run `npm run patterns` (Python 3 with numpy and scipy) to rewrite `patterns/` and refresh the copy embedded in `index.html`.

### The .pat line family

```
angle, x-origin, y-origin, delta-x, delta-y [, dash-1, dash-2, ...]
```

Line *k* of a family passes through `origin + k * (delta-x * u + delta-y * n)`, where `u` is the line direction and `n` is perpendicular to it, so the delta is measured in the family's rotated frame. The dash sequence starts at that point: positive values draw, negative values are gaps, `0` is a dot. With no dashes the lines are continuous.

## Development

`npm test` runs the parser and dash generation tests and checks the library (Node 20+). `npm run embed` copies `patterns/` into `index.html`. Third-party `.pat` files used for testing are not part of this repository.
